#DESCRIPTION : 
The project is built primarily using Python for the backend and HTML/CSS for the frontend.
It uses the concept of sockets to enable real-time communication between clients and the server. 
Through this project, I wanted to understand how data is transmitted between users and how a server can handle multiple clients at once.

At the core of this project is the backend.py file. 
This script acts as the server. When users start the application and connect to the server, they become clients.
The server keeps track of all the connected users and handles message broadcasting. 

This means whenever one client sends a message, the server receives it and sends it to all other connected clients. 
This allows for real-time communication similar to group chat applications.

The user interface is built using HTML for structure and CSS for styling. The frontend is simple but effective. 
It provides a space for users to enter their messages and see chat history.
I wanted the design to be easy to understand, especially for new users or learners who want to build something similar.

One of the key features of this chat application is its ability to handle multiple clients at once. 
I achieved this using Python’s socket programming and threading modules. 
Threads allow the server to manage multiple clients simultaneously, so each user gets instant responses without delays or conflicts. 
This was one of the most challenging yet rewarding parts of the project.
